# java-racingcar-precourse

## 📚 학습 목표
- 여러 역할을 수행하는 큰 함수를 단일 역할을 수행하는 작은 함수로 분리한다.
- 테스트 도구를 활용하여 프로그램의 정확성을 검증한다.
- 커밋 단위를 기능별로 나누고, 명확한 메시지를 작성한다.
---
## ⚒️ 구현할 기능 목록
### 🚘입력
- [ ] 자동차 이름을 입력받는다.
  - 쉼표 기준으로 구분
  - 각 이름은 1~5자 이내여야 함
  - 잘못된 입력 시 "IllegalArgumentException" 발생 후 종료
- [ ] 시도할 횟수를 입력받는다.
  - 숫자가 아니거나 1 미만일 경우 예외 발생

### 🏎️ 경주 진행
- [ ] 랜덤 값(0~9)를 생성한다.
  - "Randoms.pickNumberInRange(0, 9)" 사용
  - 4 이상이면 전진, 미만이면 멈춤
- [ ] 한 라운드가 끝날 때마다 각 자동차의 상태를 출력한다.

### 🏁 결과
- [ ] 최종 우승자를 계산한다.
  - 가장 많이 전진한 자동차(들)를 구하기
  - 여러 명일 경우 쉼표로 구분하여 출력
